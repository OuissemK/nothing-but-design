# Nothing But Design

A responsive creative portfolio built as a front-end development practice project, focusing on visual design, interactive elements, and accessibility.

## Live Demo

[View the website](https://ouissemk.github.io/nothing-but-design/)

## Technologies

- HTML5
- Tailwind CSS v4
- Vanilla JavaScript
- CSS animations and transitions

## Features

- Responsive layouts for mobile and desktop
- Interactive eyes following pointer movement
- Interactive footer animation
- Infinite scrolling marquee
- Hover interactions on project cards
- Keyboard navigation and visible focus states
- Reduced-motion support with `prefers-reduced-motion`

## Project Structure

```text
nothing-but-design/
├── assets/
├── src/
│   ├── animation.js
│   ├── index.html
│   ├── input.css
│   └── output.css
├── index.html
├── package.json
├── package-lock.json
├── robots.txt
└── sitemap.xml
```

## About

This project was created to practice responsive web development, Tailwind CSS, JavaScript interactions, and accessibility.

It is a learning and demonstration project. The portfolio content and project links are illustrative rather than commercial.

## Deployment

Hosted with GitHub Pages.

# Nothing But Design — Français

Portfolio créatif et responsive réalisé dans le cadre d'un projet d'apprentissage en développement front-end, avec une attention particulière portée au design, aux interactions et à l'accessibilité.

## Démonstration

[Voir le site](https://ouissemk.github.io/nothing-but-design/)

## Technologies utilisées

- HTML5
- Tailwind CSS v4
- JavaScript natif (Vanilla JavaScript)
- Animations et transitions CSS

## Fonctionnalités

- Interface responsive adaptée aux mobiles et aux ordinateurs
- Animation interactive des yeux suivant les mouvements du pointeur
- Animation interactive dans le footer
- Bandeau de texte défilant en continu (marquee)
- Interactions au survol des projets
- Navigation au clavier avec indicateurs de focus visibles
- Prise en charge de `prefers-reduced-motion` pour réduire les animations

## Structure du projet

Les fichiers HTML, CSS et JavaScript sont organisés dans le dossier `src/`. Le fichier `index.html` à la racine est utilisé pour le déploiement sur GitHub Pages.

## À propos

Ce projet a été réalisé pour approfondir la pratique du responsive design, de Tailwind CSS, des interactions JavaScript et des principes d'accessibilité web.

Il s'agit d'un projet pédagogique et de démonstration. Les contenus du portfolio et les liens des projets sont fictifs.

## Hébergement

Site hébergé avec GitHub Pages.
